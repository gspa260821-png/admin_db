Pasos de ejecucion

  1. Abra SSMS y conectese a SQL Server.
  2. Abra el script descargado o copie cada bloque desde este panel.
  3. Ejecute los bloques en orden del 1 al 6.
  4. Para ETL, copie pedidos_online.csv a C:\ETL\ y habilite su lectura para el servicio SQL Server.

El navegador no se conecta a SQL Server ni guarda claves: solo organiza el script para una ejecución segura desde SSMS.
